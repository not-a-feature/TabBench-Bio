Privacy-friendly analytics

We use Cabin Analytics ↗, operated by Nic Mulvaney LTD, to measure aggregate reach and improve this research website. Analytics is enabled by default. You can turn it off below; an existing opt-out remains respected. When enabled, the Cabin script is loaded from scripts.withcabin.com.

According to Cabin’s documentation, it sets no cookies, stores no unique visitor identifiers, and does not fingerprint visitors. An incoming IP address is converted in server memory to a country code and then discarded without being logged. Cabin aggregates information such as the visited page, referrer, country, language, device class, browser, and operating system. To distinguish repeat visits without persistent identifiers, Cabin uses the browser’s HTTP cache and the Last-Modified response header. Cabin states that analytics data is stored and processed in Ireland, with collection endpoints in Ireland, Frankfurt, Mumbai, and Singapore. See Cabin’s technical documentation ↗ and privacy policy ↗.

You can turn analytics off or back on at any time using the setting below. Your choice is saved in local storage in this browser and applies to subsequent page loads on this website. Clearing browser storage resets analytics to on. Turning analytics off does not undo statistics already sent. No automated decisions or personal visitor profiles are created.
