Open data

One canonical result bundle.

The SQLite database is the source for independent analysis and reproduction of derived metrics.

The database contains recorded attempts, predictions, probabilities, held-out targets, run status, resource measurements, and cell configurations. The interactive website uses a generated dashboard payload, which is not presented as a separate scientific result artifact.
